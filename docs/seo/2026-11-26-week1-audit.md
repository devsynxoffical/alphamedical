# Alpha Medi Assist: Week 1 SEO Audit (26 Nov 2026)

Sources: live crawl of all 85 sitemap URLs on https://alphamediassist.com (26 Nov), Google Search Console via Windsor.ai (16 to 24 Nov 2026, the data available), and this repository.

## 0. Blocker: this repository is not the live site

The live site is a pre-rendered React app with full SEO tags, `/denial-codes/*`, 20 blog posts, Florida and Virginia pages, RCM and denial management pages. This repo (1 commit, 17 Nov) has none of that: titles are set only in the browser, there are 2 blog posts, and its sitemap points at old `www` URLs. **Code changes cannot be made safely until we know which repository or folder the live site is built and deployed from.**

## 2. Issues found (ranked)

| # | Issue | Evidence | Fix | Who |
|---|---|---|---|---|
| 1 | **No analytics or lead tracking** | No GA4 tag, no Tag Manager, no `generate_lead` event in the HTML or the JS bundle. Forms post to `/api/form-submission` untracked | Create GA4 property; add tag; fire `generate_lead` on form success and `click_to_call` on `tel:` links; mark both as key events | Owner creates GA4, dev adds code |
| 2 | **Unverified claims on every page** | "98% net collection rate" in the homepage title/description/schema; "HIPAA-compliant" appears 280 times across the site; "90+ specialties" | Owner confirms each with evidence (BAA available? how is 98% measured?). Remove or reword anything that cannot be backed up | Owner decides, dev edits |
| 3 | **Business details shared and a virtual address** | Phone `+1-424-542-7170` is also used by Zingo Assist. Florida address `7901 4th St N Ste 23684, St. Petersburg` is a mailbox-style suite also used by Zingo Assist | Get a dedicated Alpha Medi Assist number. List Florida as a service-area business (address hidden) or drop it from listings. Confirm the Spotsylvania, VA address is staffed and eligible for Google Business Profile | Owner |
| 4 | **Heavy single JavaScript bundle** | One 1.4 MB JS file (272 KB compressed) loads on every page; no code splitting | Lazy-load routes (`React.lazy` per page) so each page loads only its own code | Dev (needs live repo) |
| 5 | **Fonts loaded twice, 4 families** | Same Google Fonts URL loaded both async and render-blocking; Outfit, Plus Jakarta Sans, Poppins, Open Sans with up to 6 weights each | Keep 1 or 2 families, only used weights, load once with `display=swap` | Dev |
| 6 | **Off-topic service** | `/healthcare-seo-services` is indexable and linked from the homepage services grid | Owner decision: noindex and remove from menus, or 301 to the agency site | Owner decides |
| 7 | **Overlapping conversion pages** | `/free-consultation` (314 words) and `/book-appointment` (229 words) do the same job | Keep one as the main CTA; point the other to it | Dev |
| 8 | **Weak internal links to newer content** | Several denial code pages (CO-24, CO-59, CO-96, CO-151, CO-252) and blog posts have only 3 to 4 internal links | Link each denial code page from the matching denial management and specialty pages; add "related codes" blocks | Dev |
| 9 | **Bot protection page on bursts** | Fast parallel requests got a "One moment, please..." page with no title | Check Search Console → Settings → Crawl stats for errors; make sure the host's bot protection allows Googlebot and Bingbot | Owner (hosting) |
| 10 | **FAQ schema on 72 pages** | Google shows FAQ rich results only for authoritative government and health sites | Harmless; keep the visible FAQs, no action needed | — |
